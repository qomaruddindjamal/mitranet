# MitraNet - Sources Directory

Direktori ini berisi image sistem operasi dasar (*base OS*) yang digunakan sebagai bahan baku rekayasa balik dan remastering MitraNet OS.

## Daftar Berkas

- `netgate-installer-amd64.iso`: Base installer image FreeBSD/Netgate OS x86_64 (~944 MB).
- `sources.md`: Laporan teknis reverse engineering lengkap mengenai arsitektur, bootloader, kernel, dan paket bawaan.

> **Catatan Penting:** File binary `.iso` diabaikan oleh git melalui file `.gitignore` agar repositori tetap ringan dan tidak melampaui batas ukuran GitHub (100MB).
