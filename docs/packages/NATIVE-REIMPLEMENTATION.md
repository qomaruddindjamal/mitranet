# MitraNet Rinjani 1.0.2 — Native Reimplementation Architecture

## 1. Overview

Phase 2C addresses all 15 BSD-specific utilities classified under Category C (`REIMPLEMENT-NATIVELY`). Instead of attempting to port or wrap FreeBSD binaries, each utility has been replaced with a clean Linux-native service leveraging:
- Python 3 standard library
- Linux netfilter / nftables
- Linux in-tree network stack & netlink
- systemd daemons and timer units
- Linux `/proc` and `/sys` virtual filesystems

---

## 2. Reimplemented Services Architecture

### 2.1 FilterLog (`FilterLogService`)
- Replaces FreeBSD `filterlog` (which parsed pf logs via `/dev/pflog`).
- On Linux, parses standard netfilter/nftables logging output generated by rule:
  ```
  log prefix "NFT-BLOCK: "
  ```
- Extracts protocol, interfaces, source/destination IPs and ports directly into structured dictionaries for the MitraNet logging engine.

### 2.2 FilterDNS (`FilterDNSService`)
- Replaces FreeBSD `filterdns` (which modified pf tables using ioctl).
- On Linux, performs non-blocking resolution of domain names and generates atomic nftables commands:
  ```
  add element inet mitranet <set_name> { <resolved_ip_list> }
  ```

### 2.3 DHCPLeases (`DHCPLeasesWatcher`)
- Replaces FreeBSD `dhcpleases` and `dhcpleases6`.
- Watches and parses Linux standard lease storage (`dnsmasq.leases` or Kea lease files) and extracts MAC, IP, and hostname mappings.

### 2.4 System Metrics (`SystemMetricsCollector`)
- Replaces FreeBSD `cpustats`, `rate`, and `qstats`.
- Reads directly from Linux `/proc/stat`, `/proc/meminfo`, and `/proc/net/dev`, eliminating external binary dependencies.

### 2.5 Status Reloader (`StatusReloaderService`)
- Replaces FreeBSD `check_reload_status`.
- Manages reload flag files in `/run/mitranet` and coordinates reloads for firewall, routing, and DNS services.

### 2.6 Proxy ARP (`ProxyARPService`)
- Replaces FreeBSD `choparp`.
- Manages kernel `/proc/sys/net/ipv4/conf/<iface>/proxy_arp` or executes native `ip neigh add proxy` commands.

### 2.7 Table Expiry (`TableExpiryService`)
- Replaces FreeBSD `expiretable`.
- Uses native Linux `nftables` stateful set timeout capabilities (`flags timeout; timeout 3600s;`), pushing entry expiration into the Linux kernel netfilter engine rather than requiring a userspace poller.
