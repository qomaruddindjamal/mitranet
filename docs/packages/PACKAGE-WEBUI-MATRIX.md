# MITRANET — PACKAGE WEB UI MATRIX

**Official Identity:** MitraNet 0.1.0-dev (Code OS: Rinjani)

## 1. Web UI Presentation Mapping
- **Direct UI Modules**:
  - `interfaces/`: Supported by network drivers, interface utilities, and VLAN tools.
  - `firewall/`: Supported by packet filter engines, aliases, and blacklist modules.
  - `routing/`: Supported by dynamic routing engines (FRR) and routing table utilities.
  - `vpn/`: Supported by WireGuard, OpenVPN, StrongSwan, and Xray.
  - `packages/`: Supported by package inventory, system audit, and update utilities.
- **Backend Libraries**: Function as invisible foundational dependencies; no dummy UI buttons created.
